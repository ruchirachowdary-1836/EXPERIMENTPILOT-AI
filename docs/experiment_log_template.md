# Experiment log (template)

Copy one block per benchmark or analysis run. Never overwrite earlier entries.

```
## <YYYY-MM-DD> – <short title>
- Git commit:
- Config file + hash:
- Command:
- Seeds (estimation / evaluation):
- Hypothesis / question:
- Result summary (link to research/results/… files):
- Deviations from the pre-registered protocol (docs/evaluation.md):
- Surprises / failures:
- Next step:
```

Rules: record negative results; do not tune thresholds on evaluation seeds; note any change to experiment thresholds, injectors or likelihood smoothing and re-estimate the tables if they change.
